راهنمای سیستم Nobitex Trading Pro (ویندوز)

اسکنر خودکار، تحلیل فیبوناچی و داشبورد تعاملی نوبیتکس برای ویندوز

نحوه راه‌اندازی سریع در ویندوز (1-Click Run)

برای اجرای داشبورد روی ویندوز نیازی به نوشتن دستورات پیچیده ندارید:

  1. وارد پوشه پروژه شوید.
  2. روی فایل run_windows.bat دو بار کلیک کنید.
  3. برنامه به صورت خودکار محیط پایتون را آماده کرده و داشبورد وب را در مرورگر شما به آدرس http://localhost:8000 باز می‌کند!

اجرای دستورات از طریق ترمینال (PowerShell / Command Prompt)

در صورتی که قصد دارید اسکریپت‌ها را دستی اجرا کنید:

# ساخت و فعال‌سازی venv در ویندوز:
python -m venv venv
venv\Scripts\activate

# نصب پیش‌نیازها:
pip install requests pandas numpy plotly

# اجرای اسکنر اصلی تحت وب:
python app.py

شرح فایل‌ها و خروجی‌های پروژه

فایلتوضیح و عملکرد
app.pyسرور اصلی داشبورد پایتون (سازگار با ویندوز) جهت اجرای اسکن و ارائه APIها
gui/index.htmlرابط کاربری مدرن تحت وب (Glassmorphic SPA) با نمودارهای کندل‌استیک فیبوناچی
run_windows.batفایل راه‌اندازی ۱-کلیکی برای اجرا روی ویندوز بدون تداخل کدگذاری
src/nobitex_scan_dynamic.pyموتور کشف پویای نمادها و تحلیل اولیه نوسان
fib_support_signal.pyتحلیل سطح حمایت فیبوناچی، MA50 و کانال‌های قیمتی

نکات مدیریت ریسک و معامله‌گری

  • همواره پیش از ثبت سفارش حقیقی، میزان نقدینگی و عمق دفتر سفارشات (Orderbook) نوبیتکس را بررسی کنید.
  • سیگنال‌های خرید (Long) هنگامی معتبرتر هستند که حداقل یک کندل ۱ ساعته بالای نقطه ورود تثبیت شود.
  • لغزش قیمت (Slippage) و کارمزد معاملات به صورت خودکار در محاسبات سود خالص این سیستم لحاظ شده‌اند.
