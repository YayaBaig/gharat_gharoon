خلاصهٔ محتوای فایل README.md
README outline (نمونه کوتاه): nobitex_trading معرفی، ویژگی‌ها، ساختار پروژه، پیش‌نیازها، نصب، نحوه اجرا، نمونه دستورات: نصب وابستگی‌ها (requests, pandas, numpy, plotly) اجرای اسکن پویا: python src/nobitex_scan_dynamic.py تولید گزارش نهایی (کندل 1h + محاسبات با کارمزد و لغزش): python src/nobitex_signals_nominal_fees_with_ohlc_rounded.py --capital 10000 --taker-fee 0.001 --slippage 0.002 --nobitex-token "$NOBITEX_TOKEN" مکان خروجی‌ها: پوشه output/
خلاصهٔ محتوای guide.html
راهنما شامل: نصب و راه‌اندازی virtualenv نمونه دستورات اجرا توضیح خروجی‌ها (CSV و HTML) راهنمای خواندن نمودار (کندل‌ها، نقاط ورود/استاپ/تارگت) پیشنهادات کاهش ریسک و نکات عملیاتی

نکات پایانی که گفتگو با آن تمام می‌شود
مطمئن شو همه اسکریپت‌ها header برای خواندن متغیر NOBITEX_TOKEN یا پارامتر --nobitex-token را دارند. برای اجرا در سرور: از virtualenv و systemd استفاده کن و لاگ‌ها را بچسبان به فایل‌های rotating log. اگر بخواهی، من نسخه نهایی README.md و guide.html را با محتوای فارسی دقیق‌تر در یک فایل ZIP آماده می‌کنم یا تغییراتی مثل اضافه کردن نمونه‌های تصویری داخل HTML را اضافه کنم.
