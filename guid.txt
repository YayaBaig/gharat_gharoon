### فایل README.md

```markdown
# nobitex_trading

نخستین نسخه ابزار اسکن و تولید سیگنال برای بازارهای USDT در نوبیتکس (apiv2).  
این پروژه ابزارهای خط فرمانی برای کشف نمادها، گرفتن کندل 1h از endpoint UDF/history، محاسبه اندیکاتورها، فیلتر بر اساس نوسان و نقدینگی، تولید سیگنال‌های قابل بررسی و ساخت گزارش عددی و نمودار تعاملی HTML فراهم می‌کند.

## ویژگی‌ها
- کشف پویا نمادهای USDT با بررسی orderbook
- گرفتن OHLC (کندل 1h) از endpoint رسمی و محاسبه EMA, RSI, MACD, Bollinger Bands
- فیلتر بر اساس نوسان و حجم دلاری
- تولید سیگنال‌های Long/Short با محاسبه entry/stop/target
- محاسبه اندازه پوزیشن بر اساس تخصیص کل سرمایه یا درصد ریسک
- محاسبه خالص سود و ریسک پس از احتساب کارمزد و لغزش
- خروجی CSV با عناوین فارسی و نمودار HTML شامل کندل‌استیک 1h و نقاط ورود/استاپ/تارگت

## ساختار پروژه
- src/: اسکریپت‌های پایتون
- data/: داده‌های خام و cache
- output/: خروجی‌های CSV و HTML
- docs/: نمونه‌ها و changelog

## پیش‌نیازها
- Python 3.8+
- بسته‌های پایتون:
  - requests
  - pandas
  - numpy
  - plotly
  نصب سریع:
  ```bash
  python -m venv venv
  source venv/bin/activate
  pip install --upgrade pip
  pip install requests pandas numpy plotly
  ```

## نحوه استفاده سریع
1. متغیر توکن (اختیاری برای OHLC) را ست کن:
   ```bash
   export NOBITEX_TOKEN="your_token_here"
   ```
2. اسکن دینامیک و تولید CSV اولیه:
   ```bash
   python src/nobitex_scan_dynamic.py
   ```
   خروجی: `output/nobitex_dynamic_scan.csv`

3. تولید گزارش عددی و HTML با تخصیص سرمایه (مثال):
   تمام سرمایه به هر سیگنال اختصاص داده می‌شود و محاسبات با کارمزد و لغزش انجام می‌شود.
   ```bash
   python src/nobitex_signals_nominal_fees_with_ohlc_rounded.py --capital 10000 --taker-fee 0.001 --slippage 0.002 --nobitex-token "$NOBITEX_TOKEN"
   ```
   خروجی‌ها:
   - `output/خلاصه_سیگنال‌ها_نوبیتکس_ساده_گرد.csv`
   - `output/نوبیتکس_سیگنال‌ها_با_کندل_1h_گرد شده تا 2 رقم اعشار.html`

4. باز کردن HTML:
   فایل HTML را در مرورگر باز کن؛ نمودارها تعاملی‌اند و می‌توانی زوم کنی یا نقاط را نشان‌دار کنی.

## فایل‌های مهم و توضیح کوتاه
- src/nobitex_scan_dynamic.py: کشف نمادهای معتبر و تولید `nobitex_dynamic_scan.csv`
- src/nobitex_ohlc_scan_apiv2.py: نمونهٔ ساده برای گرفتن OHLC و تولید یک سیگنال برای یک نماد
- src/nobitex_signals_nominal_fees_with_ohlc_rounded.py: نسخه نهایی؛ محاسبات با کارمزد و لغزش و گرد شده به ۲ رقم اعشار؛ خروجی CSV ساده و HTML با کندل 1h
- output/: محل قرارگیری همه CSV و HTML تولیدشده

## نکات امنیتی و عملیاتی
- توکن API را در متغیر محیطی نگه دار؛ هرگز در مخزن عمومی commit نکن.
- برای اجرای خودکار در سرور، از systemd یا cron با کنترل حافظه و لاگ استفاده کن.
- قبل از اجرای اتوماتیک سفارشات واقعی، هر سیگنال را دستی چک کن و orderbook را همیشه بررسی کن.

## توسعه و نگهداری
تغییرات را در `docs/changelog.txt` ثبت کن و کد جدید را در `src/` اضافه کن. برای اضافه کردن استراتژی یا اندیکاتور جدید یک فایل جدید بساز و از توابع مشترک موجود استفاده کن.
```

### دستورات شل پیشنهادی برای مرتب‌سازی محلی

- ایجاد دایرکتوری‌ها و انتقال فایل‌ها:
```bash
mkdir -p nobitex_trading/{src,data/raw,data/cache,output,docs}
# فرض بر این است فایل‌های اسکریپت فعلی در مسیر جاری هستند
mv nobitex_*.py nobitex_scan_*.py nobitex_signals_*.py nobitex_scan_dynamic.py nobitex_ohlc_scan_apiv2.py src/ || true
mv nobitex_dynamic_scan.csv output/ || true
mv *.html output/ || true
mv *.csv output/ || true
# اضافه کردن README و guide
# سپس درون nobitex_trading ریشه، فایل README.md و docs/guide.html را قرار بده
```
